Динамика по неделям

Недели разбиты по календарным дням месяца. Процент — факт / план, может быть выше 100%. Высота столбца ограничена 100% для наглядности.

🔒 Данные хранятся только в этом браузере на этом устройстве. Для сохранности можно сделать резервную копию.

Как пользоваться дневником

  1. Добавьте привычку и выберите дни, когда планируете заниматься.
  2. Отмечайте галочками фактические дни. Если бассейн был в пятницу вместо четверга, отметьте пятницу. План по четвергам сохранится.
  3. Дополнительные занятия тоже считаются. План — 1 раз, факт — 2 раза: выполнение 200%, сверх плана +1.
  4. Отчёты показывают план, факт, процент и перевыполнение. Стрелки позволяют посмотреть другие недели и месяцы.
  5. Данные сохраняются в этом браузере. Регулярно скачивайте резервную копию; для переноса на другое устройство используйте восстановление из файла.
  6. Тема переключается круглой кнопкой справа внизу.

Нельзя отмечать будущие даты. Если план равен нулю, процент не рассчитывается, но фактические занятия учитываются.
