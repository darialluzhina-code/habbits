# Мои привычки

Локальный дневник привычек в браузере. Можно планировать занятия на неделю, отмечать фактические дни, смотреть отчёты и хранить резервную копию на компьютере. Данные не отправляются на сервер.

## Что внутри

- Приветственная страница `index.html`
- Дневник `app.html`: привычки, недельная сетка, отчёты, импорт и экспорт
- Светлая и тёмная тема
- Хранение в `localStorage` на этом устройстве

Формат сохранения `habits-diary-v1` совместим с прежним однофайловым вариантом.

## Как запустить

Самый простой способ — открыть `index.html` в браузере.

Либо поднять локальный сервер из корня проекта:

```bash
npm start
```

Сервер слушает [http://127.0.0.1:4173](http://127.0.0.1:4173). Для запуска нужен Python 3.

## Как пользоваться

1. Откройте дневник и добавьте привычку с днями плана.
2. Ставьте галочки в дни, когда занятие реально состоялось. Незапланированный день тоже можно отметить — он пойдёт сверх плана.
3. Смотрите недельный и месячный отчёты. Стрелками листаются прошлые периоды.
4. Периодически скачивайте резервную копию JSON. На другом устройстве её можно восстановить из файла.

Будущие даты отметить нельзя. Если на период нет плана, процент не считается, но факты в отчёте остаются.
